# 晴海かけっこ教室 ホームページ

事業譲渡資料（かけっこ教室_事業譲渡概要資料.pptx）の内容をもとに作成した、静的なホームページ一式です。
サーバー不要のHTML/CSS/JSのみで構成されているので、そのままレンタルサーバーや無料ホスティング（Netlify、GitHub Pages、Cloudflare Pagesなど）にアップロードすれば公開できます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | トップページ（LP形式・全セクション入り） |
| `privacy.html` | 個人情報保護方針 |
| `terms.html` | 利用規約 |
| `style.css` | 共通スタイル |
| `script.js` | ナビ・フォーム・アニメーションなどの動作 |

ローカルで確認するときは `index.html` をダブルクリックしてブラウザで開くだけでOKです。

## 🟡 決めてから直すもの（現在は仮の内容）

4. **体験レッスン料**：現在「無料」と表示しています（体験→入会の導線として一般的な設定です）。
   有料にする場合は `index.html` 内の「体験料」「無料で体験してみる」「無料体験レッスンに申し込む」などの表記を修正してください。

5. **教室名・ロゴ**：仮称として「晴海かけっこ教室」、ロゴは走る子どもをモチーフにしたSVG（HTML内に直接記述）を使用しています。
   名称を変える場合は全ファイルを「晴海かけっこ教室」で一括置換してください。

6. **コーチ紹介**：現在は「近日公開」の表示です。コーチが決まったら `index.html` の COACH セクションに氏名・写真・経歴・実績を記載してください。

7. **保護者の声**：現在はCOMING SOON表示です。実際の声が集まったら、
   `index.html` の VOICE セクションの `soon-panel` を声のカードに差し替えてください。

8. **退会ルール（前月末までに連絡）や振込期日**：利用規約・FAQに一般的な内容で記載しています。実際の運用に合わせて調整してください。

## 🟢 あとからでよいもの

9. **写真・動画**：「教室の雰囲気」セクションはイラストのプレースホルダーです。
   実際の写真が用意できたら `<figure class="gallery-tile">…</figure>` を `<img>` に置き換えてください（掲載には保護者の同意を得てください）。
10. **SNSリンク**：お問い合わせセクションのInstagram / X / YouTubeアイコンは「準備中」表示です。開設後に `href="#"` をアカウントURLに変えて `sns-disabled` クラスを外してください。
11. **お知らせ**：`index.html` の「お知らせ」セクション（`news-list`）に新しい項目を上から追記していく運用です。
